# Unichat +

Messagerie unifiée internationale (Android, iPhone, web) — phase 1.

- Connexion sans mot de passe (code e-mail), un seul appareil actif
- Profil, compte professionnel, téléphone facultatif
- Discussions en temps réel, photos, documents
- Modifier / supprimer pour moi / supprimer pour tous, sans limite de temps
- Accusés : envoyé ✓, distribué ✓✓, lu ✓✓ bleu (désactivable)
- Messages éphémères : 24 h, 7 jours, 90 jours ou durée personnalisée
- Groupes : propriétaire, administrateurs, modérateurs, permissions, invitations, liens, demandes d'adhésion
- 8 langues (français, anglais, espagnol, portugais, arabe, chinois, swahili, lingala)

Backend : Supabase (projet `unichat-plus`).

## APK

Chaque envoi sur la branche `unichat-plus` compile automatiquement l'APK (onglet **Actions**),
puis le publie dans **Releases → unichat-apk → unichat-plus.apk**.
